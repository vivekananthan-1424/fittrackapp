# FitTrack Java V5
- Visible logout button and session invalidation.
- Daily activity CRUD via existing save/upsert and delete endpoints.
- Meal create/read/update/delete; edit recalculates nutrition automatically.
- Water create/read/delete retained.
- Workout create/read/delete added.
- Expanded veg/non-veg food catalog inherited from V4.1.
- Profile update/password change, admin dashboard, weight trends, BMI, and automatic activity estimates retained.

Note: a hard-coded catalog cannot contain every food. Production-scale food coverage requires a vetted nutrition API/database.
